# 배터리/접지 스택 그룹핑이 seed 요소 하나만 기준으로 비교한다

`lib/circuit-recognition/classify.ts`의 `groupParallelStacks`는 배터리(교대로
쌓인 평행판)와 접지(점점 짧아지는 평행판) 기호를 찾기 위해 후보 선분을
묶는다. 이때 후보가 스택에 들어갈 수 있는지는, 스택을 시작한 seed 요소 `g`의
`center`(수직 스택이면 x, 수평 스택이면 y)와만 비교하고, 이미 스택에 들어간
다른 요소들의 정렬은 다시 확인하지 않는다.

지금 검증된 샘플에서는 문제가 없었지만, 우연히 같은 seed의 center와 허용
오차 안에 들어오는 서로 무관한 작은 소자 두 개가 있으면 하나의 가짜
배터리/접지 스택으로 합쳐질 수 있다.

스택에 새 요소를 추가할 때 seed뿐 아니라 스택 전체의 평균 정렬과 비교하도록
바꾸면 될 것으로 보인다. 실제로 이런 오분류가 나오는 샘플이 확인되면
재검토한다.
